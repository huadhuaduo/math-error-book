## 三智能体工作流

```
/scenario/generate     ← 场景生成智能体
  选场景 → 跳转
/scenario/:id/chat     ← 对话智能体（AI插件驱动NPC）
  自由对话 → detection-rules检测决策点 → 完成 → 跳转
/scenario/:id/feedback ← 反馈智能体（feedback-assembler组装+AI润色）
  三层输出 → 再练一次 / 回案例库
```
