🎯 七、关键设计决策

决策 1：Skill 不是替代 CLAUDE.md，而是执行它。每个 Skill 的第一步都是读取 CLAUDE.md 和对应 memory 文件获取最新定义，而不是在 Skill 中固化规则文本。这样当 CLAUDE.md 更新时，Skill 行为自动跟随。
决策 2：双文件存储策略。每个 Skill 同时保存为 .skill 包（供 Claude Code 系统加载）和 SKILL.md 源文件（供人类阅读和版本控制）。.skill 是 zip 压缩格式，SKILL.md 是纯文本 markdown。
决策 3：Skill 之间可互相触发。对标检查如果发现重大差异，自动建议触发专家团评审。专家团评审中识别的方法论不一致，按 CLAUDE.md 一.4 格式单独报告。不形成循环依赖，但保持信息流动。
决策 4：里程碑制，非每次触发。里程碑同步不要求每次小改动都执行——那会打断工作流。只在4种里程碑节点触发：功能上线验证通过、对话结束、重大版本发布前、Claude产出新文件时。
决策 5：对标不是为了抄。对标报告的核心价值在交叉分析——单家分析只是输入，四家交叉对比才能得出有意义的结论。"四家都在做的事"是行业基线必须做，"各家做法不同的事"是有选择空间的，"四家都没做的事"需要警惕是否行不通。
