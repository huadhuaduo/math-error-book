## 一、架构差异（根因）

| 维度 | 本地文件 | 线上文件 |
|---|---|---|
| 框架 | 纯 HTML + 内联 JS | React 18 + TypeScript + Framer Motion + Tailwind |
| 页面数 | 3 独立 HTML 文件 | 1 SPA（3 路由：/tg001/prepare → engine → feedback） |
| AI 调用 | ❌ 对话页 0 处 capabilityClient 调用 | ✅ 流式调用 `capabilityClient.load().callStream()` |
| 数据流 | localStorage 键不匹配（tg001_post_eval vs tg001_session_data）| ✅ `tg001_session_{sessionId}` + `tg001_prep_self_eval` + `tg001_post_eval` 三者一致 |
| 引擎逻辑 | 散落在 `tg001_context_engine.js` / `tg001_hybrid_engine.js` | 收束在 `tg001-engine-logic.ts` + `tg001-feedback-logic.ts` 双文件 |
| 陷阱检测 | 部分（T03/T04） | 完整 7 类（T01/T03/T04/T05/T06/T08/**T09含修复**） |
| NPC-周 System Prompt | ❌ 不在本地任何文件中 | ✅ 在 `tg001-engine-logic.ts` 的 `getTG001SystemPrompt()` 中 |
| UI 组件 | 纯 HTML | TG001SidePanel（独立组件）+ 入场动画 + Framer Motion 过渡 |
