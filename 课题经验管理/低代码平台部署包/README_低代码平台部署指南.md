## 部署步骤

### 第 1 步：在低代码平台新建页面

1. 打开低代码平台项目，进入页面管理
2. 新建一个页面，命名为「课题经验资产库」
3. 页面路径设为 `/keti-lessons`（或你喜欢的路径）

### 第 2 步：粘贴 HTML 内容

1. 打开本地文件 `课题经验资产库.html`
2. **全选复制**（Cmd+A → Cmd+C）
3. 在低代码平台页面编辑器中，切换到「源码」或「HTML」模式
4. **清空默认内容，粘贴全部代码**
5. 保存

### 第 3 步：验证

1. 在低代码平台中预览/发布页面
2. 访问页面，确认看到 5 个 tab：`经验录入 | 成果录入 | 条目库 | 生成报告 | 备份`
3. 录入一条测试数据 → 保存 → 刷新页面 → 确认数据还在（localStorage 正常）
4. 生成经验报告 → 确认五段式深度报告正常渲染

## 数据安全说明

| 安全维度 | 状态 |
|----------|------|
| 数据存储位置 | 仅用户浏览器 localStorage |
| 网络请求 | **0 个**（无 fetch/XHR/外部资源） |
| 第三方依赖 | **0 个**（纯原生 JS，无 npm/CDN） |
| 数据离开浏览器 | **不会** — 录入、分类、报告全在浏览器本地完成 |
| 低代码平台服务器接触数据 | **不会** — 低代码平台只托管 HTML 文件，不接触 localStorage |

**数据备份**：使用工具内「备份」tab → 导出 JSON → 存到本地文件夹。低代码平台部署版本和本地 HTML 版本的备份文件完全通用。

---

## 低代码平台注意事项

1. **localStorage 容量**：低代码平台已验证支持 ≥2.4KB（单条约 0.5-1KB，可存数百条）
2. **同域名隔离**：localStorage key 为 `lessonBank_v4`，不会与低代码平台其他应用冲突
3. **打印功能**：`window.print()` 在低代码平台 iframe 中可能受限，建议在浏览器新标签页中打开使用
4. **文件上传**（PPTX/DOCX/TXT 提取）：依赖 `DecompressionStream` API，需要 Chrome 80+ / Safari 16.4+，低代码平台浏览器环境通常支持
