## 方式一：React 三智能体（推荐·AI 驱动）

### 你需要做什么

在低代码平台项目里新建 5 个文件 + 加 3 行路由。**全是复制粘贴，不需要写代码。**

### 第 1 步：打开低代码平台项目文件树

在低代码平台编辑器左侧找到 `client/src/` 目录。

### 第 2 步：放 3 个页面文件

| 本地文件（一键部署包里） | 放到低代码平台哪里 |
|------------------------|------------|
| `ScenarioGenerate.tsx` | `client/src/pages/ScenarioGenerate.tsx` |
| `ScenarioChat.tsx` | `client/src/pages/ScenarioChat.tsx` |
| `ScenarioFeedback.tsx` | `client/src/pages/ScenarioFeedback.tsx` |

**操作**：在低代码平台文件树 `client/src/pages/` 上右键→新建文件→输入文件名→打开本地文件全选复制→粘贴到低代码平台→保存。

### 第 3 步：放 2 个工具文件

| 本地文件 | 放到低代码平台哪里 |
|---------|------------|
| `detection-rules.ts` | `client/src/utils/detection-rules.ts` |
| `feedback-assembler.ts` | `client/src/utils/feedback-assembler.ts` |

操作同上。

### 第 4 步：加 3 条路由

在低代码平台文件树找到路由文件（通常是 `client/src/app.tsx` 或 `client/src/router.tsx`），打开。找到 `<Routes>` 标签，在里面已有的 `<Route>` 旁边加上：

```tsx
<Route path="/scenario/generate" element={<ScenarioGenerate />} />
<Route path="/scenario/:sceneId/chat" element={<ScenarioChat />} />
<Route path="/scenario/:sceneId/feedback" element={<ScenarioFeedback />} />
```

文件顶部加上这三行 import：

```tsx
import ScenarioGenerate from './pages/ScenarioGenerate';
import ScenarioChat from './pages/ScenarioChat';
import ScenarioFeedback from './pages/ScenarioFeedback';
```

### 第 5 步：验证

保存所有文件，等待低代码平台编译完成。浏览器访问 `/scenario/generate`。

## 常见问题

**Q：`.tsx` 文件怎么打开？**
A：不需要在本地打开。在低代码平台编辑器中新建文件，把内容粘贴进去。

**Q：部署后页面空白？**
A：打开浏览器 F12 控制台，看红色报错信息。最常见的原因是路由没配或 import 路径不对。

**Q：对话页 NPC 不回应？**
A：确认 `ScenarioChat.tsx` 顶部有 `import { capabilityClient } from '@lark-apaas/client-toolkit';`。如果 AI 插件名不对，改成低代码平台实际的插件名。

**Q：后端文件要不要部署？**
A：如果之前 Step 1-3（数据库/Service/Controller）已经部署过，跳过。一键部署包里的 `server_coaching.*.ts` 和 `db_migration.sql` 是给首次部署用的。
