## 验证步骤

### Step 1：在 TG001EnginePage.tsx 中新增 AI 注入函数

在文件顶部 import 区域确认已有：
```typescript
import { capabilityClient } from '@lark-apaas/client-toolkit';
```

在 `sendMsg` 函数之前，新增 `callAI` 工厂函数：
```typescript
const callAI = async (
  systemPrompt: string,
  history: Array<{ role: string; content: string }>,
  timeoutMs: number
): Promise<string | null> => {
  const plugin = capabilityClient.load('mdp_coach_ai_conversation_reply_1');
  const result = await plugin.call('textGenerate', {
    system_prompt: systemPrompt,
    user_message_history: JSON.stringify(history.slice(-10)),
  });
  const text = (result as { content?: string; text?: string }).content
    || (result as { content?: string; text?: string }).text;
  return text?.trim() || null;
};
```

### Step 2：修改 sendMsg 中的引擎调用

找到当前 `sendMsg` 函数中调用 AI 的部分，替换为：
```typescript
import { respond, createInitialState } from './dialogue-agent_engine';
import TG001Config from './TG-001_v2.0.json';

// 组件内初始化
const config = TG001Config as ScenarioCard;
const [engineState, setEngineState] = useState(createInitialState());

// sendMsg 中：
const result = await respond(
  config,
  text,
  conversationHistory,  // history 参数
  engineState,
  callAI               // ← 注入妙搭 AI 调用
);
setEngineState(result.state);

const npcResp = result.response;
// result.layer: 'L1'(缓存) | 'L2'(AI成功) | 'L3'(回应池) | 'L4'(兜底)
// result.events: [{type:'trap', msg:'...'}, {type:'whisper', msg:'...'}]
```

### Step 3：打开 Console，发送测试消息

1. 打开 TG001 对话页
2. 打开浏览器 Console（F12 → Console）
3. 在对话输入框发送一条消息，例如："你帮我看看最近数据怎么样"

## 通过标准

- [ ] **NPC 正常回复**：老周回复了与"数据/项目"相关的内容（非兜底文本）
- [ ] **Console 无报错**：没有 `undefined is not a function` 或 `capabilityClient.load is not a function` 等错误
- [ ] **Console 日志**：如果引擎内有 `console.log` 输出 `B路线·L2 AI成功` 或类似日志，说明 AI 调用成功
- [ ] **回复内容具体**：老周的回复跟你的提问相关（不是通用回应如"老周看了你一眼..."）

## 失败排查

| 症状 | 可能原因 | 解决 |
|------|---------|------|
| `capabilityClient is not defined` | import 未生效 | 检查 `import { capabilityClient } from '@lark-apaas/client-toolkit'` |
| `plugin.call is not a function` | 插件名称错误 | 确认插件名称为 `mdp_coach_ai_conversation_reply_1` |
| NPC 回复了通用兜底文本 | AI 调用失败，走了 L4 降级 | 检查 `callAI` 是否正确传入 `respond()` 的第 5 个参数 |
| NPC 回复了回应池文本 | AI 调用失败，走了 L3 降级 | `callAI` 返回了 null — 检查插件调用超时/报错 |
| 页面白屏 | JSON 导入路径错误 | 检查 `TG-001_v2.0.json` 文件路径 |
