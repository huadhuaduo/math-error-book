## 二、低代码平台配置步骤

### Step 1：创建 AI 节点

1. 在低代码平台中新建一个页面或流程
2. 添加一个 **AI 对话/生成节点**
3. 将 `场景生成智能体_Prompt.md` 的**完整内容**粘贴到 System Prompt 字段

### Step 2：配置输入参数

在 AI 节点前添加表单输入（下拉选择或文本输入），收集以下参数：

| 参数字段 | 类型 | 选项值 |
|---------|------|--------|
| D₁ 士气根源 | 下拉 | 过劳衰竭 / 缺乏意义感 / 缺乏公平感 / 缺乏安全感 |
| D₂ 压力模式 | 下拉 | 短期冲刺 / 结构转型 / 流程重建 / 收尾维稳 |
| D₃ 经验构成 | 下拉 | 资深为主 / 资浅为主 / 混合两极 |
| D₄ 激励资源 | 下拉 | 丰富 / 有限 / 极度受限 |
| D₅ 信任基础 | 下拉 | 已有信任 / 需要建立 / 存在裂痕 |
| D₅ 裂痕类型 | 下拉（条件显示：仅 D₅=存在裂痕 时出现） | 显性冲突 / 隐性对抗 |
| P 步骤范围 | 多选 | P₁诊断 / P₂信任 / P₃目标 / P₄激励 / P₅赋能 / P₆闭环 |
| 难度等级 | 下拉 | basic / medium / advanced |

### Step 3：配置输出

AI 节点输出为 JSON 字符串。在低代码平台中：

1. 添加一个 **JSON 解析节点**（或使用 JS 节点解析 JSON.parse()）
2. 将解析后的场景卡数据传给下游节点
3. **建议**：下游接一个 HTML 渲染节点，用 `场景卡预览器.html` 的渲染逻辑展示场景卡

### Step 4：验收测试

1. 在低代码平台中运行一次场景生成
2. 将输出的 JSON 复制到 `场景卡预览器.html` 中
3. 点击"渲染预览" → 人工通读场景卡
4. 验收标准：找一个真实管理者看——"这个人我认识"才算通过

## 三、场景卡预览器使用

`场景卡预览器.html` 是一个**独立的 HTML 文件**，可以在浏览器中直接打开。用途：

1. **开发阶段**：把场景生成智能体输出的 JSON 粘贴进去 → 渲染 → 人工验收
2. **低代码平台上线前**：快速预览场景卡内容，检查 D 向量、决策点、陷阱标注是否正确
3. **团队协作**：生成的 HTML 可以直接截图分享给专家评审

功能：
- ✅ JSON 粘贴 → 人类可读的场景卡渲染
- ✅ 自动校验（D向量完整性/决策六要素/P序列/陷阱标注）
- ✅ 加载示例（TG-001 数据）
- ✅ 纯前端·数据不离开浏览器

## 四、安全性和落地性检查 ✅

### 安全性（对标 security-rules.md 8 条铁律）

| # | 规则 | 检查结果 |
|---|------|---------|
| 1 | 无 XSS via innerHTML | ✅ 预览器使用 `textContent` 或 `esc()` 转义后再 innerHTML |
| 2 | 无 alert/confirm/prompt | ✅ 使用自定义 toast 通知 |
| 3 | 无 eval/new Function | ✅ 使用 JSON.parse() 解析数据 |
| 4 | 无外部 CDN | ✅ 零外部依赖，纯内联 CSS/JS |
| 5 | HTML 转义 | ✅ esc() 函数贯穿所有动态内容渲染 |
| 6 | 无数据外泄 | ✅ 预览器和 Prompt 都无 fetch/XHR 调用 |
| 7 | 输入净化 | ✅ 用户输入仅通过 JSON.parse 处理，渲染前全部转义 |
| 8 | 数据隐私 | ✅ Prompt 不要求上传任何用户数据。所有数据在低代码平台内闭环。 |

### 落地性（低代码平台兼容性）

| 检查项 | 结果 |
|--------|------|
| Prompt 自包含 | ✅ 所有规则内嵌在单个 Prompt 中，无需引用外部文件 |
| Prompt 长度 | ⚠️ 约 8000 字。低代码平台的 System Prompt 字段通常支持 10000-20000 字，在范围内。如超过限制，可删除第七章的 JSON 示例（保留 Schema）和第九章的 Few-shot 示例 |
| JSON 输出格式 | ✅ 使用"输出格式锁"——禁止在 JSON 前后添加解释文字 |
| 输入参数化 | ✅ D 向量和 P 步骤通过表单参数传入 |
| 行业适配 | ✅ 默认地产行业。Prompt 第八节提供了行业语料触发词。扩展到其他行业时需修改第八节 |

## 五、已知限制 & 注意事项

1. **大模型能力依赖**：场景生成智能体的输出质量取决于低代码平台所选的大模型。建议使用推理能力较强的模型（如 Claude Opus 4 / GPT-4 级别）
2. **场景验收必须人工**：JSON 校验通过了 ≠ 场景真实。必须找真实管理者通读
3. **行业语料需要积累**：当前 Prompt 内置了地产行业语料触发词。扩展到其他行业时，需要新增对应行业的语料词表
4. **反馈智能体未包含**：本包只含场景生成智能体。对话智能体和反馈智能体是后续交付的内容
