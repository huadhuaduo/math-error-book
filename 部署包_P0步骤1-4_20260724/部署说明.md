## 架构关系

```
场景卡JSON (TG-001_v2.0.json)
    │                          ← 唯一真相源
    ├── 🗣️ 对话引擎 (dialogue-agent_engine.ts)
    │   ├── 读 dialogue_mode → 决定AI调用策略
    │   ├── 读 system_prompt → 传给AI插件
    │   ├── 读 response_pool → AI降级时使用
    │   ├── 读 prompt_rules → 陷阱检测+上下文推进+自动推进
    │   └── 依赖: condition-evaluator.ts (安全条件求值)
    │
    └── 📊 反馈引擎 (feedback-agent_generator.ts)
        ├── 读 learning_theory → 分发模块组
        ├── 读 success_criteria → 评分维度+行为对照步骤
        ├── 读 feedback_modules → 声明渲染顺序
        └── 模块组: constructivism.ts (管理陪练)
            └── 判词(L2模板+原话) + 觉察(L2模板+原话) + 行为对照(规则+原话提取) + L1模块×3
```

## 部署步骤

### Step 1：上传文件

将 7 个 ts/tsx 文件上传到妙搭项目对应目录。

### Step 2：TG001 对话页接入新引擎

在 TG001EnginePage.tsx 中，替换当前 sendMsg 逻辑：
```typescript
import { respond, createInitialState } from './dialogue-agent_engine';
import TG001Config from './TG-001_v2.0.json';

// 初始化
const config = TG001Config as ScenarioCard;
const [state, setState] = useState(createInitialState());

// sendMsg中调用
const result = await respond(config, text, history, state);
setState(result.state);
// 使用 result.response / result.layer / result.events
```

### Step 3：TG001 反馈页接入新引擎

在 TG001FeedbackPage.tsx 中：
```typescript
import { generateFeedback } from './feedback-agent_generator';
import TG001Config from './TG-001_v2.0.json';

const modules = await generateFeedback(TG001Config as ScenarioCard, sessionData);
// 按 modules 数组顺序渲染
```
