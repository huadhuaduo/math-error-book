测试 3：中间数据能否存储

验证场景卡 JSON（约5-10KB）能否在页面间持久化——三智能体链路需要它

测试 3a：localStorage 读写

模拟一张场景卡（约 3KB），测试写入→读取→关闭页面→重新打开→读取

在低代码平台上测试时：先点"写入"，关闭浏览器标签页，重新打开这个页面，点"读取"——看数据是否还在。
⚠️ 如果低代码平台页面运行在 iframe 或沙箱中，localStorage 可能被禁用。

测试 3b：URL 参数传递

测试通过 URL 参数传递场景卡 ID（大数据不通过 URL 传，只传 ID 指向 localStorage）

适用于：场景生成页 → 跳转对话页时传递 scenario_id。
对话页通过 scenario_id 从 localStorage 读取完整场景卡。
⚠️ URL 总长度不超过 2000 字符，所以只传 ID，不传完整 JSON。

测试 3c：低代码平台全局变量/状态（需在低代码平台中手动验证）

此测试无法自动化——需要你在低代码平台界面中手动检查以下功能是否存在：

  1. 低代码平台的页面/流程编辑器中，是否有"全局变量"或"状态管理"面板？
  2. AI 节点的输出是否可以绑定到变量？
  3. 变量是否可以在同一流程的不同节点之间共享？
  4. 变量是否可以在不同页面之间共享？
