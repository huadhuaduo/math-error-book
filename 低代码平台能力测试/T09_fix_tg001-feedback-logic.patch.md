## 问题

`getManagementInertia` 函数只检查 T03（信息幻觉）/ T04（给工具替代行动）/ trustAsked，不检查 T09。
陷阱计数会 +1，但"觉察 · 你的模式"区块文字不会提及"加班施压/拿你是问"——导致核对项 1 ❌。

## 修改

在 `getManagementInertia` 函数中，**`const hasInfoTrap = ...` 之前**插入：

```typescript
const hasPressure = traps.T09 >= 1;
if (hasPressure) {
  return {
    title: '面对"不信"时，你的默认策略——用压力和问责推动执行',
    evidence: '全员加班到晚上十点、取消周末休息、做不到拿你是问——当团队缺乏信心时，你的第一反应是施加更大的压力和问责，而不是替他们减轻负担。',
    analysis: '压力在短期内可能让团队表面服从，但对NPC-周这种见过四任领导的资深员工来说，施压等于宣告"我不信任你们的能力"。他表面点头，内心已经关上了门。真正能让资深团队行动起来的，不是更大的压力，而是有人替他们承担"砍错了怎么办"的风险。',
  };
}
```

## 影响范围

- 仅影响 `getManagementInertia` 函数，新增一个最高优先级 if 分支
- 不影响现有 T03/T04/trustAsked 分支
- 无 T09 时行为完全不变（向后兼容）
