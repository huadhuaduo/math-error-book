# 低代码平台能力边界测试方案

> **目的**：验证低代码平台是否支持三智能体串联——AI节点串联、JSON传递、中间数据存储
> **方法**：3 个最小化测试，每个 5 分钟可完成
> **原则**：用最简单的内容测最核心的能力，不写复杂逻辑

---

## 测试 1：单 AI 节点能否输出结构化 JSON？

### 测什么
AI 节点的 System Prompt 中指定 JSON 输出格式 → AI 是否严格输出 JSON（不带解释性文字）？

### 怎么测
1. 在低代码平台中新建一个页面，添加一个 **AI 节点**
2. System Prompt 粘贴以下内容：

```
你是一个测试助手。用户会给你三个词，你需要把它们组织成 JSON 格式输出。

你必须只输出 JSON。不得在 JSON 前后添加任何解释、markdown 标记、或额外文字。输出必须以 { 开始，以 } 结束。

JSON 格式：
{
  "words": ["词1", "词2", "词3"],
  "count": 3,
  "reversed": ["词3", "词2", "词1"]
}
```

3. 用户输入：`苹果 香蕉 橘子`
4. 观察 AI 输出

### 通过标准
- ✅ AI 输出的是纯 JSON（可以复制出来用 JSON.parse 解析成功）
- ❌ AI 在 JSON 前后加了 "好的，这是您的 JSON：" / ```json ... ``` 等文字

### 如果不通过
Prompt 需要更强的"输出格式锁"。加这句话：
> 如果你在 JSON 前后添加了任何文字，你的整个输出将被视为失败。直接输出 `{`。

## 测试 2：两个 AI 节点能否串联传 JSON？

### 测什么
节点 A 输出 JSON → 节点 B 能否收到这个 JSON 并基于它做处理？

### 怎么测
**节点 A** — System Prompt：
```
你是一个数据生成器。用户给你一个数字 N，你输出一个 JSON 数组，包含 N 个 1-100 之间的随机整数。

你必须只输出 JSON。格式：
{ "numbers": [数字列表], "sum": 总和 }
```

**节点 B** — System Prompt：
```
你是一个数据分析器。你会收到一个 JSON 对象，格式为 { "numbers": [数字列表], "sum": 总和 }。
你需要输出一个新的 JSON：
{
  "original": [原数字列表],
  "sum": 原总和,
  "average": 平均值(保留2位小数),
  "max": 最大值,
  "min": 最小值,
  "above_average": [所有大于平均值的数字]
}

你必须只输出 JSON。
```

### 串联方式（按低代码平台的实际界面选择）

**方式 A：工作流串联**
如果低代码平台有工作流/流程编排功能：
- 节点 A 的输出 → 设为节点 B 的输入
- 用户只需在第一个节点输入，后续自动流转

**方式 B：前端 JS 桥接**
如果低代码平台只有独立 AI 节点，但可以嵌入 HTML/JS：
- 用 JS 调用节点 A → 拿到 JSON → 传给节点 B
- 测试页 HTML 写在下方

### 通过标准
- ✅ 节点 B 输出的 JSON 中 `average`/`max`/`min` 值计算正确
- ❌ 节点 B 收到的是空值或报错
- ❌ 节点 B 收到了 JSON 但被当作字符串处理（average 是错的）

### 方式 B 的测试 HTML

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>低代码平台节点串联测试</title>
<style>
  body { font-family: -apple-system, sans-serif; max-width: 600px; margin: 40px auto; padding: 20px; }
  .section { margin: 20px 0; padding: 16px; border: 1px solid #e5e7eb; border-radius: 8px; }
  .section h3 { margin-top: 0; }
  pre { background: #f5f5f5; padding: 12px; border-radius: 6px; font-size: 12px; overflow-x: auto; }
  .pass { color: #2d8a56; font-weight: bold; }
  .fail { color: #c44; font-weight: bold; }
  button { padding: 8px 20px; margin: 5px; cursor: pointer; }
  input { padding: 8px; width: 80px; }
</style>
</head>
<body>
<h2>低代码平台节点串联测试</h2>

<div class="section">
  <h3>Step 1: 节点 A — 生成数据</h3>
  <label>输入数字 N：<input type="number" id="inputN" value="5" min="1" max="20"></label>
  <button onclick="runNodeA()">运行节点 A</button>
  <div id="outputA"></div>
</div>

<div class="section">
  <h3>Step 2: 节点 B — 分析数据</h3>
  <button onclick="runNodeB()">将节点A的输出传给节点B</button>
  <div id="outputB"></div>
</div>

<div class="section">
  <h3>Step 3: 验证结果</h3>
  <div id="validation"></div>
</div>

<script>
var dataFromA = null;

function runNodeA() {
  // 在低代码平台中，这里替换为调用 AI 节点的代码
  // 以下是本地模拟——部署时替换为实际的低代码平台 AI 调用
  var n = parseInt(document.getElementById('inputN').value) || 5;
  var numbers = [];
  var sum = 0;
  for (var i = 0; i < n; i++) {
    var num = Math.floor(Math.random() * 100) + 1;
    numbers.push(num);
    sum += num;
  }
  dataFromA = { numbers: numbers, sum: sum };
  document.getElementById('outputA').innerHTML = '<pre>' + JSON.stringify(dataFromA, null, 2) + '</pre>';
}

function runNodeB() {
  if (!dataFromA) {
    document.getElementById('outputB').innerHTML = '<span class="fail">❌ 没有节点A的数据。请先运行节点A。</span>';
    return;
  }
  
  // 在低代码平台中，这里替换为调用 AI 节点 B 的代码
  // 传入 dataFromA 作为输入
  var numbers = dataFromA.numbers;
  var sum = dataFromA.sum;
  var avg = sum / numbers.length;
  var max = Math.max.apply(null, numbers);
  var min = Math.min.apply(null, numbers);
  var aboveAvg = numbers.filter(function(n){ return n > avg; });
  
  var result = {
    original: numbers,
    sum: sum,
    average: parseFloat(avg.toFixed(2)),
    max: max,
    min: min,
    above_average: aboveAvg
  };
  
  document.getElementById('outputB').innerHTML = '<pre>' + JSON.stringify(result, null, 2) + '</pre>';
  
  // Validate
  var checks = [];
  checks.push({ label: 'average计算', pass: Math.abs(result.average - avg) < 0.01 });
  checks.push({ label: 'max正确', pass: result.max === max });
  checks.push({ label: 'min正确', pass: result.min === min });
  checks.push({ label: 'sum传递', pass: result.sum === sum });
  
  var html = '';
  for (var i = 0; i < checks.length; i++) {
    html += '<div class="' + (checks[i].pass ? 'pass' : 'fail') + '">' + (checks[i].pass ? '✅' : '❌') + ' ' + checks[i].label + '</div>';
  }
  document.getElementById('validation').innerHTML = html;
}
</script>

</body>
</html>
```

## 测试 3：能否存储中间数据（场景卡缓存）？

### 测什么
场景生成智能体产出的场景卡（JSON 约 5-10KB），能否在低代码平台中暂存——供对话智能体和反馈智能体后续读取？

### 三种可能方案（按优先级）

**方案 A：低代码平台内置变量/状态管理**
如果低代码平台有全局变量或状态存储功能：
- 节点 A 输出 → 存入变量 `scenario_card`
- 节点 B 从变量 `scenario_card` 读取

**方案 B：localStorage（浏览器端）**
如果低代码平台允许自定义 JS：
```javascript
// 存
localStorage.setItem('scenario_card', JSON.stringify(scenarioCard));

// 读
var scenarioCard = JSON.parse(localStorage.getItem('scenario_card'));
```

**方案 C：URL 参数传递**
如果低代码平台页面间可以通过 URL 参数传递数据：
- 场景生成页 → 将 JSON 编码为 URL 参数 → 跳转对话页
- 限制：URL 长度限制（约 2000 字符），场景卡可能超长
- 替代：用 `encodeURIComponent` + 分块

### 怎么测
1. 在低代码平台中创建一个测试页面
2. 尝试写入一个大 JSON（约 3000 字符）到 localStorage
3. 关闭页面 → 重新打开 → 读取
4. 检查数据是否完整

### 测试用的 localStorage 读写脚本

```html
<script>
var testData = {
  scenario_id: 'TEST-001',
  context: { /* 填充约 2000 字符的模拟数据 */ },
  decision_points: [ /* 2-3 个模拟决策点 */ ]
};

// 写测试
function writeTest() {
  try {
    localStorage.setItem('mdp_test', JSON.stringify(testData));
    var size = new Blob([JSON.stringify(testData)]).size;
    document.getElementById('result').textContent = '写入成功。数据大小：' + size + ' 字节';
  } catch(e) {
    document.getElementById('result').textContent = '写入失败：' + e.message;
  }
}

// 读测试
function readTest() {
  var raw = localStorage.getItem('mdp_test');
  if (raw) {
    var data = JSON.parse(raw);
    document.getElementById('result').textContent = '读取成功。场景ID：' + data.scenario_id;
  } else {
    document.getElementById('result').textContent = '未找到数据';
  }
}
</script>
```
