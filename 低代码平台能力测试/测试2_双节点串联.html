🔗 低代码平台串联方式

⚠️ 请在低代码平台中确认使用哪种串联方式。不确定的话——三种都试一遍。
方式 A：工作流串联

如果低代码平台有"工作流"或"流程编排"：

节点 A 输出 → 配置为节点 B 的输入。AI 节点之间有连线。

方式 B：前端 JS 桥接

如果低代码平台允许嵌入自定义 HTML/JS：

JS 调用节点 A API → 拿到 JSON → 传给节点 B API。

方式 C：手动串联

如果以上都不行：

手动复制节点 A 的输出 → 粘贴到节点 B 的输入。

🧪 测试步骤

  1. 在低代码平台中配置节点 A 和节点 B 的 System Prompt（上方）
  2. 用户输入 8 到节点 A
  3. 观察节点 A 输出 JSON → 传给节点 B
  4. 检查节点 B 输出的 average/max/min 是否基于节点 A 的数据正确计算
