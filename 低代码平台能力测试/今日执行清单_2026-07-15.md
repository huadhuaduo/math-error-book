## 测试 1：AI 节点输出纯 JSON（10 分钟）

**在低代码平台里做：**
1. 新建测试应用/页面，添加一个 AI 节点
2. System Prompt 粘贴（一字不改）：

```
你是一个测试助手。用户会给你三个词，你需要把它们组织成 JSON 格式输出。

你必须只输出 JSON。不得在 JSON 前后添加任何解释、markdown 标记、或额外文字。输出必须以 { 开始，以 } 结束。

JSON 格式：
{
  "words": ["词1", "词2", "词3"],
  "count": 3,
  "reversed": ["词3", "词2", "词1"]
}
```

3. 运行，输入：`苹果 香蕉 橘子`
4. **复制 AI 的完整输出** → 粘贴到 `测试1` 验证页 → 看判定结果

**判定：**
- ✅ 验证页显示解析成功 → 记录"通过"，进入测试 2
- ❌ AI 加了 ```json 标记或说明文字 → 在 Prompt 末尾追加下面一行，重跑一次：
  > 如果你在 JSON 前后添加了任何文字，你的整个输出将被视为失败。直接输出 `{`。
- 重跑仍失败 → 记录失败原因和 AI 原始输出（这决定后续所有 Prompt 都要加"格式锁"）

**记录**：填 `测试结果记录.md` 测试 1 表格，粘贴 AI 完整输出。

## 测试 2：双节点串联传 JSON（15 分钟）

**在低代码平台里做：**
1. 添加第二个 AI 节点。两个节点的 System Prompt：

**节点 A（数据生成器）：**
```
你是一个数据生成器。用户给你一个数字 N，你输出一个 JSON 数组，包含 N 个 1-100 之间的随机整数。

你必须只输出 JSON。格式：
{ "numbers": [数字列表], "sum": 总和 }
```

**节点 B（数据分析器）：**
```
你是一个数据分析器。你会收到一个 JSON 对象，格式为 { "numbers": [数字列表], "sum": 总和 }。
你需要输出一个新的 JSON：
{
  "original": [原数字列表],
  "sum": 原总和,
  "average": 平均值(保留2位小数),
  "max": 最大值,
  "min": 最小值,
  "above_average": [所有大于平均值的数字]
}

你必须只输出 JSON。
```

2. **先找工作流串联**（优先）：在低代码平台里找"工作流 / 流程编排 / 节点连线"功能，把 A 的输出接到 B 的输入。找 3 分钟，找不到就换下一种。
3. **找不到工作流 → 手动复制中转**：运行 A（输入 `5`）→ 复制 A 的输出 → 粘贴给 B 运行。
   ⚠️ 手动中转也是有效测试——它验证"节点 B 能否理解 JSON 输入"这一核心能力；串联机制本身记录为"不支持工作流"即可。
4. 把 A 和 B 的输出分别粘贴到 `测试2` 验证页 → 自动校验 average/max/min 是否算对

**判定：**
- ✅ B 的计算基于 A 的真实数据且数值正确 → 通过
- ⚠️ B 输出了 JSON 但数值算错 → 部分通过（记录：AI 计算不可靠，数值计算必须放 JS 层——这会直接影响反馈智能体的评分设计）
- ❌ B 无法处理 → 记录失败形态

**记录**：填测试 2 表格，**务必写下"低代码平台中配置串联的具体操作步骤"**（这是部署方式 A 的关键情报）。

## 测试 3：中间数据存储（15 分钟）

**3a. localStorage（最关键——方式 B 部署的命脉）**
1. 在低代码平台里新建一个自定义页面，嵌入 `测试3_中间数据存储.html` 的内容（或直接把文件上传/粘贴到低代码平台的 HTML 组件里）
2. 点"写入测试"（写入约 3KB 模拟场景卡）→ 显示写入成功和字节数
3. **关闭该页面 → 重新打开** → 点"读取测试" → 数据是否还在？
4. ⚠️ 注意：必须在**低代码平台环境内**测，不是本地浏览器——低代码平台可能用 iframe 沙箱隔离 localStorage，本地测通过不代表低代码平台里通过

**3b. 页面间跳转 + localStorage**
1. 在低代码平台里建第二个页面，同样嵌入读取脚本
2. 从页面 1 写入 → 跳转到页面 2 → 能否读到？
3. 这直接对应"准备页 → 对话页 → 反馈页"的数据流

**3c. 低代码平台全局变量（手动检查，5 分钟封顶）**
- 低代码平台有没有"全局变量/状态管理"功能？AI 节点输出能否绑定到变量？变量能否跨页面？
- 有 → 逐项勾选；没有 → 全勾"没有"，不纠结

**记录**：填测试 3a/3b/3c 表格。
