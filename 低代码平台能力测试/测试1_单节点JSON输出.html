测试 1：AI 节点能否输出纯 JSON

验证低代码平台 AI 节点是否严格遵循"只输出 JSON"的指令

📋 低代码平台 System Prompt（复制到低代码平台 AI 节点的 System Prompt 字段）

🧪 测试步骤

  1. 在低代码平台中新建页面，添加一个 AI 对话节点
  2. 将上方 System Prompt 粘贴到节点的 System Prompt 字段
  3. 用户输入：苹果 香蕉 橘子
  4. 观察 AI 的回复

✅ 判定标准

通过：AI 只输出了 JSON，可以直接复制到下方验证框通过 JSON.parse 解析。

不通过：AI 在 JSON 前后加了任何文字，如"好的，这是您的JSON："或 ```json ``` 标记。

如果不通过：在 Prompt 末尾追加一句——"如果你在 JSON 前后添加了任何文字，你的整个输出将被视为失败。直接输出 {。"

🔍 验证工具（将低代码平台 AI 输出粘贴到下方）
