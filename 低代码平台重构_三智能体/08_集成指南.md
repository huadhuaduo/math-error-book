# 集成指南 · 三智能体架构

> 如何将以下文件集成到已有低代码平台项目

---

## 一、文件映射

| 新文件 | 放到项目的哪里 | 说明 |
|--------|-------------|------|
| `01_类型定义.ts` | `src/types/scenario-card.ts` | 所有智能体共用的类型契约 |
| `02_数据库Schema.sql` | 在数据库管理工具中执行 | 给已有表加字段·不建新表 |
| `03_路由配置.tsx` | 追加到已有路由文件 | 新增 4 条路由 |
| `04_场景生成智能体.tsx` | `src/pages/ScenarioGenerate.tsx` | 场景生成页 |
| `05_对话智能体.tsx` | `src/pages/ScenarioChat.tsx` | 对话决策页 |
| `06_反馈智能体.tsx` | `src/pages/ScenarioFeedback.tsx` | 反馈页 |
| `07_数据流串联.ts` | `src/hooks/useCoaching.ts` | API 封装 + 插件调用 |

## 二、集成步骤（按顺序）

### Step 1：数据库迁移（2 分钟）

在数据库管理工具中执行 `02_数据库Schema.sql`。
不建新表——只给已有的 `coaching_scenes` 和 `coaching_sessions` 加字段。

### Step 2：添加类型文件（1 分钟）

把 `01_类型定义.ts` 放到 `src/types/scenario-card.ts`。

### Step 3：添加路由（2 分钟）

把 `03_路由配置.tsx` 中的 4 条 `<Route>` 追加到已有 `<Routes>` 中。

检查已有的 `coaching_scenes` 和 `coaching_sessions` 表是否有对应的 API 路由。如果没有，需要新增以下 API：

```
POST   /api/coaching-scenes          ← 创建场景（已有？）
GET    /api/coaching-scenes/:id      ← 读取场景（已有？）
POST   /api/coaching-sessions        ← 创建会话（已有？）
PATCH  /api/coaching-sessions/:id    ← 更新会话决策路径
GET    /api/coaching-sessions/:id    ← 读取会话（已有？）
```

### Step 4：放置页面文件（5 分钟）

把 04-06 的 `.tsx` 文件放到 `src/pages/` 目录。

### Step 5：启动场景生成页（首次测试）

1. 访问 `/scenario/generate`
2. 选择 D 向量参数 → 点击"生成场景卡"
3. 如果场景生成插件 `scenario_card_smart_generate_v19_1` 还未部署，先部署插件
4. 插件部署后，前端只传 4 个结构化参数——Prompt 由插件内部维护

### Step 6：验证完整链路

```
/scenario/generate → 选参数 → 生成场景卡
  ↓
/scenario/:id/chat → 叙事 → 决策点 → 选 A/B/C → 看后果
  ↓
/scenario/:id/feedback?session=X → 三层报告 → 再练一次
```

## 三、需要确认的事项

| 事项 | 确认人 |
|------|--------|
| `scenario_card_smart_generate_v19_1` 插件是否已部署？ | 你 |
| `coaching_scenes` 表的 API 路由是否已存在？ | 你 |
| `coaching_sessions` 表的 API 路由是否已存在？ | 你 |
| 项目是否使用 React Router v6？ | 你 |
| 项目是否有 `capabilityClient` 全局对象？ | 你 |

## 四、旧代码怎么处理

- **不删、不改、不迁移。**
- 旧 HTML 文件留在原处——需要参考管理者B场景内容时打开看看。
- 新代码不走旧代码的任何逻辑。
- 两边独立运行——旧的继续工作，新的从 `/scenario/generate` 开始。

## 五、如果某个插件还没部署

如果 `scenario_card_smart_generate_v19_1` 还没部署：
- 插件 Prompt 来自 [场景生成智能体_Prompt.md](../低代码平台部署_场景生成智能体/场景生成智能体_Prompt.md)
- 在低代码平台插件管理中创建新插件 → 粘贴 Prompt → 前端调用时只传参数
