# 三智能体架构 · 低代码平台重构

> V19.1 · 2026-07-13 · 从零重建，不迁移旧代码

---

## 核心原则（3条·跟旧架构的彻底决裂）

| 旧架构 | 新架构 |
|--------|--------|
| 独立 HTML 文件·手动串联 | React SPA·路由 + SearchParams 串联 |
| localStorage 存储 | PostgreSQL JSONB 字段 |
| Prompt 写死在 HTML 里 | AI 插件内部维护 Prompt·前端只传参数 |
| 准备页→对话页→反馈页 耦合 | 三智能体独立页面·通过 URL params + DB 传递数据 |
| 一个任务域 = 一套独立代码 | 所有任务域共享三智能体·只换配置 |

---

## 数据流

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  场景生成页 /scenario/generate                               │
│  ├─ 用户选择 D 向量 + P 步骤 + 难度                          │
│  ├─ 调用插件 scenario_card_smart_generate_v19_1              │
│  ├─ 输出：场景卡 JSON → 存入 coaching_scenes 表              │
│  └─ 跳转：/scenario/:sceneId/chat                            │
│                                                             │
│  对话页 /scenario/:sceneId/chat                               │
│  ├─ 从 DB 读取场景卡                                         │
│  ├─ 叙事推进 → 决策点触发 → 收集选择                          │
│  ├─ 调用插件 mdp_coach_ai_conversation_reply_1               │
│  ├─ 决策路径存入 coaching_sessions.decision_path (JSONB)     │
│  └─ 全部决策点完成 → 跳转 /scenario/:sceneId/feedback?session=│
│                                                             │
│  反馈页 /scenario/:sceneId/feedback?session=X                 │
│  ├─ 从 DB 读取场景卡 + 决策路径                               │
│  ├─ 调用插件 ai_coach_analysis_report_1                      │
│  └─ 渲染三层输出：理论透镜·行业校准·专家做法                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 页面清单（4个·足够）

| 路由 | 页面 | 功能 |
|------|------|------|
| `/scenario/generate` | 场景生成页 | D向量表单 → 调用AI插件 → 场景卡入库 → 跳转对话 |
| `/scenario/:sceneId/chat` | 对话决策页 | 读场景卡 → 叙事→决策点→收集路径 → 跳转反馈 |
| `/scenario/:sceneId/feedback?session=X` | 反馈页 | 读场景卡+决策路径 → 调用分析插件 → 三层输出 |
| `/scenario/:sceneId/preview` | 场景预览页 | 只读展示场景卡·验收用 |
